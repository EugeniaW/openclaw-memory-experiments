# Repo rules

This repository is for pilot experiments only.

Goals:
- build a minimal, checkable experiment pipeline for an OpenClaw memory study
- consume hand-curated pilot fixtures from the dataset repo
- output one markdown report and one csv summary

Do not:
- invent research findings
- claim statistical significance
- fabricate missing raw data
- modify the dataset repo

Preferred workflow:
- plan first
- implement small, reviewable pieces
- keep outputs explicit and traceable
